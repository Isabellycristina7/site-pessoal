- JavaScript

## Como executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/[seu-usuario]/site-pessoal-isabelly.git
   ```
2. Entre na pasta:
   ```bash
   cd site-pessoal-isabelly
   ```
3. Abra o arquivo `index.html` no navegador.
